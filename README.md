# Mole Racing Track Builder – Prototype 21

Open `index.html` directly in your browser.

## Changed in Prototype 21

- Replaced the browser popup with an inline angle field beside Placement Assist.
- Select a barrier and type the exact angle directly in the toolbar.
- Press Enter or click elsewhere to apply the angle.
- Press Escape to cancel the current edit.
- Decimal values are supported.
- Negative angles and values above 360° are normalized automatically.
- The field updates when another barrier is selected.
